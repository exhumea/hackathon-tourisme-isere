# Context documents

Quick index of the reference material used to frame the project. Read
`topo_prez.md` first; it summarises the hackathon's intent and data landscape.

| Document | What it contains |
|---|---|
| `topo_prez.md` | Synthesis of the DGE kick-off slides: goals, Isère territory, problem statements, data catalog, team notes. |
| `topo_interne.md` | Internal presentation of the hackathon: context, objectives, audience, practical info. |
| `topo_web.md` | Copy of the public event page (programme, partners, deliverables). |
| `reglement_hackathon.md` | Official rules: expected deliverables, judging, licensing (Apache 2.0 or MIT). |
| `reglement_hackathon.docx` | Same rules in Word format, as distributed by the organisers. |
| `ideation_claude_pendant_prez.md` | Exploratory notes: data sources to investigate, POC ideas, conventions and known pitfalls. |
